A Wi-Fi router's confession: "I know, I died right as the killer was
revealed. I kept you online for two hours and forty-seven minutes — the
climax was simply the last straw." The program writes it to
`/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
